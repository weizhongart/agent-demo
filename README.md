# agent-demo

## 电商管理后台 - 用户管理功能

这是一个轻量的前端示例，实现了电商管理后台中的用户管理模块，开箱即用，无需安装依赖。

### 功能清单

- 用户列表展示（用户名、邮箱、手机号、角色、状态、注册时间、最后登录）
- 关键词搜索（用户名/邮箱/手机号）
- 状态筛选、角色筛选与一键重置
- 新建用户、编辑用户、删除用户
- 用户启用/禁用切换
- 关键数据统计卡片（总数、正常、禁用、VIP）
- 本地持久化（`localStorage`）

### 如何使用

1. 直接用浏览器打开 `index.html`
2. 进入页面后即可进行用户管理操作
3. 数据会自动保存到浏览器本地存储

### 文件结构

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：交互与业务逻辑
